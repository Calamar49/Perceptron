# Simulador del Perceptrón

Simulador interactivo del Perceptrón de Rosenblatt (NumPy puro, sin scikit-learn) — entrena AND, OR y XOR época por época, con frontera de decisión, convergencia y el modelo matemático en vivo.

Taller de Inteligencia Artificial — mismo algoritmo que `ANALISIS_PERCEPTRON.ipynb`.

## Correr localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Desplegar

Este repo está listo para desplegarse directo en [Streamlit Community Cloud](https://share.streamlit.io) — apunta a este repositorio y a `app.py`.
